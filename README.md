# ANIOR Sneakers

Step into tomorrow. A premium, high-performance streetwear and sneaker e-commerce platform built with React.

## 🚀 Features
* **Apple-Style Highlight Slider:** Immersive, horizontal hover-to-play background video highlights.
* **Full-Bleed Media Layout:** Video-driven cinematic home user experience.
* **Optimized Asset Pipeline:** Uses the public directory framework for fast content streaming.
* **Authentication Flow:** Secure router integration.
